# Java 📚

Repositório focado em **projetos e códigos em Java**, incluindo:

- ✅ Refatoração de projetos originalmente desenvolvidos em C
- 📖 Projetos do curso de **ADS (Análise e Desenvolvimento de Sistemas)** da Fatec Sorocaba
- 🎯 Disciplinas do 2º e 3º semestres
- 🚀 Projetos pessoais desenvolvidos do zero
- 📈 Documentação do meu aprendizado e evolução na linguagem

## 🎯 Objetivo

Manter um portfólio organizado de projetos Java, demonstrando progressão técnica e aplicação de conceitos aprendidos durante o curso.

## 📁 Estrutura do Repositório

O repositório está organizado por tópicos e projetos, facilitando a navegação e compreensão do conteúdo.

## 🛠️ Tecnologias

- **Linguagem**: Java
- **Plataforma**: JVM

## 📝 Como Usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/JoseCBJ/Java.git
   ```
2. Navegue até o projeto desejado
3. Siga as instruções específicas de cada projeto
